# Radix brand

The mark is a slice, a voxel region, three roots, and three feature dots. The wordmark is Radix.

![Radix](brand/radix-logo-horizontal.svg)

Rules live in the brand book: [brand/radix-brand-book.pdf](brand/radix-brand-book.pdf). Colors and type tokens are in [brand/radix-tokens.css](brand/radix-tokens.css).

| Token | Value | Use |
|---|---|---|
| `--radix-blue` | `#3C8DCC` | Mark |
| `--radix-deep` | `#1E3550` | Wordmark, dark ground |
| `--radix-sky` | `#75B9F8` | Mark on dark ground |
| `--radix-mist` | `#EAF3FC` | Pale ground |
| `--radix-ink` | `#151D27` | Text |
| `--radix-slate` | `#5F6873` | Secondary text |
| `--radix-amber` | `#F2B84B` | Highlight |
| `--radix-font` | Poppins, system-ui, sans-serif | Wordmark and UI |

The mark is drawn bold so it holds up at 16 px: eight voxels, a 7 px slice, 6 px roots.
